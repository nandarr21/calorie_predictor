Tentang Aplikasi

Aplikasi ini merupakan implementasi Regresi Linear Sederhana untuk memprediksi jumlah kalori yang terbakar berdasarkan durasi olahraga.

📋 Deskripsi Aplikasi

Calorie Burn Predictor adalah aplikasi web yang dikembangkan untuk menganalisis hubungan antara durasi olahraga dan jumlah kalori yang terbakar, serta mengimplementasikannya dalam aplikasi web Flask yang interaktif.

Aplikasi menggunakan Regresi Linear Sederhana (Simple Linear Regression) dengan satu variabel input (Duration) untuk memprediksi satu variabel output (Calories).

📐 Variabel Model

Peran Nama Kolom Satuan Keterangan
Input (X) Duration Menit Durasi olahraga yang dilakukan
Output (Y) Calories kcal Estimasi kalori yang terbakar

🧮 Metode

Metode yang digunakan adalah Linear Regression (Regresi Linear Sederhana). Model memodelkan hubungan linier antara satu variabel independen dan satu variabel dependen:

Y = β₀ + β₁X + ε

Di mana β₀ adalah intercept, β₁ adalah slope (koefisien), X adalah Duration, Y adalah Calories, dan ε adalah residual/error.

🗃️ Dataset

Dataset yang digunakan adalah Calories Burnt Prediction Dataset, sebuah dataset publik yang tersedia di Kaggle. Dataset terdiri dari dua file:

  • exercise.csv — berisi data olahraga termasuk kolom Duration
  • calories.csv — berisi data kalori terbakar (kolom Calories)

Kedua file digabungkan menggunakan kolom User_ID, kemudian hanya kolom Duration dan Calories yang digunakan sebagai input dan output model.
