🔍 Bagian 3 — Interpretasi Metrik
R²
R² menunjukkan seberapa besar variasi jumlah kalori terbakar yang dapat dijelaskan oleh Duration dalam model.
Nilai R² = {{ stats.r2 }} berarti sekitar {{ (stats.r2 * 100) | round(2) }}% variasi Calories pada data testing dapat dijelaskan oleh Duration dalam model ini.
MAE
MAE menunjukkan rata-rata selisih absolut antara nilai aktual dan nilai prediksi dalam satuan kcal.
Nilai MAE = {{ stats.mae }} kcal berarti rata-rata kesalahan prediksi model adalah sekitar {{ stats.mae }} kcal pada data testing.
MSE
MSE menunjukkan rata-rata kuadrat kesalahan antara nilai aktual dan nilai prediksi. Semakin kecil nilai MSE, semakin kecil kesalahan prediksi.
Nilai MSE = {{ stats.mse }} kcal². Karena MSE menggunakan kuadrat, nilainya lebih sensitif terhadap kesalahan yang besar dibandingkan MAE.
RMSE
RMSE menunjukkan besar kesalahan prediksi dalam satuan kcal. Nilai yang lebih kecil menunjukkan prediksi yang lebih dekat dengan nilai aktual.
Nilai RMSE = {{ stats.rmse }} kcal. RMSE adalah akar dari MSE sehingga memiliki satuan yang sama dengan Calories (kcal), membuatnya lebih mudah diinterpretasikan.

⚠️ Keterbatasan Model
⚠️ Keterbatasan Model
Model hanya menggunakan Duration sebagai satu-satunya variabel prediktor. Jumlah kalori yang terbakar sebenarnya dapat dipengaruhi oleh berbagai faktor lain seperti berat badan, usia, jenis kelamin, detak jantung, intensitas olahraga, dan kondisi individu.
Karena model hanya menggunakan satu variabel input, hasil prediksi merupakan estimasi berdasarkan pola pada dataset dan tidak dapat dianggap sebagai pengukuran kalori yang sebenarnya.
Model hanya valid untuk input dalam rentang data training ({{ stats.dur_min | int }}–{{ stats.dur_max | int }} menit). Penggunaan di luar rentang ini (ekstrapolasi) dapat menghasilkan prediksi yang tidak dapat diandalkan.
